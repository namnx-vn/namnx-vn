# Setup

## GitHub Profile

The profile repository must use the exact username: `NamAppro/NamAppro`.

1. Create the public repository manually on GitHub.
2. Copy this project into it.
3. Push to `main`.
4. Enable GitHub Actions.
5. Add `METRICS_TOKEN` and `WAKATIME_API_KEY` as repository secrets if those integrations are desired.
6. Run Snake and Metrics manually once.
